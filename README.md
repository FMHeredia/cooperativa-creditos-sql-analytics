Cooperativa de Ahorro y Crédito - SQL Risk & CRM Analytics

📌 Descripción
Proyecto de base de datos relacional en SQL Server enfocado en el sector solidario colombiano. Evalúa la exposición al riesgo de la cartera crediticia en COP, la morosidad según días de atraso y la relación entre la deuda y los aportes sociales de los asociados.

*Nota: Todos los datos en este Github (cédulas de ciudadanía, nombres y montos) son 100% sintéticos.*

🛠️ Estructura del Repositorio
* `01_schema.sql`: Tablas relacionales con llaves primarias y foráneas.
* `02_datos_sinteticos.sql`: Datos de prueba simulando asociados y créditos en Colombia.
* `03_consultas_analiticas.sql`: Consultas avanzadas usando CTEs, agregaciones y lógica de riesgo financiero.# cooperativa-creditos-sql-analytics
